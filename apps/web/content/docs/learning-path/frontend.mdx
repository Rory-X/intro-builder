---
title: 前端开发学习路线
description: 从 HTML/CSS 到 React 生态，前端开发的完整学习路径。
---

## 阶段一：基础（1-2 个月）

- HTML5 语义化标签
- CSS3 布局（Flex、Grid）
- JavaScript 基础（ES6+）
- 浏览器开发者工具使用

## 阶段二：框架入门（2-3 个月）

- React 基础（组件、状态、生命周期）
- TypeScript
- 包管理器（npm/pnpm）
- 构建工具基础（Vite）

## 阶段三：工程化（2-3 个月）

- React 生态（React Router、状态管理）
- CSS 方案（Tailwind CSS / CSS Modules）
- 组件库使用（Ant Design / shadcn/ui）
- Git 工作流

## 阶段四：进阶（持续）

- 性能优化（懒加载、代码分割、缓存策略）
- SSR/SSG（Next.js）
- 自动化测试（Vitest、Playwright）
- 前端监控与埋点

## 面试准备清单

- [ ] 手写 Promise / 防抖节流 / 深拷贝
- [ ] 浏览器渲染原理（重排重绘、事件循环）
- [ ] React 原理（虚拟 DOM、Fiber、Hooks 原理）
- [ ] 网络基础（HTTP/HTTPS、TCP、DNS）
- [ ] 至少 2 个可展示的项目

## 推荐资源

- MDN Web Docs（基础参考）
- React 官方文档（新版）
- 《JavaScript 高级程序设计》
- LeetCode（算法练习）

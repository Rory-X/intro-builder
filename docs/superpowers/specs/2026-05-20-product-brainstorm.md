## 1. 竞品分析与市场空白

| 竞品 | 强项 | 短板 |
|------|------|------|
| 超级简历 | AI 写作、模板多、品牌认知 | 编辑器笨重、预览不实时、PDF 偏移 |
| 木及简历 | 免费导出、简洁 | 模板陈旧、无 AI、无协作 |
| FlowCV | 实时预览、多语言 | 不懂中文排版（照片位置、政面等） |
| Reactive Resume | 开源、自部署 | UX 粗糙、中文字体渲染差、无 AI |

### 市场空白

没有一款工具同时做到：

- **实时所见即所得**（非"先填后看"）
- **中文排版原生**（避头尾、标点挤压、中英文间距）
- **AI 内容辅助**（段落级 inline 改写，不是整文替换）
- **现代编辑体验**（TipTap 富文本 + 拖拽 + 快捷键）
- **PDF 永久免费**（竞品最令人反感的付费墙）

## 2. 功能优先级矩阵

### P0 — 立即做（高影响 · 可控成本）

| # | 功能 | 用户价值 | 复杂度 | 目标人群 |
|---|------|---------|--------|---------|
| 1 | **三步引导流**：选模板 → 填基本信息 → 骨架简历自动生成 | 解决"空白页恐惧"，转化率提升 | 低 | 应届生、跳槽者 |

| 3 | **完成度评分**：环形进度 + 维度拆分（完整度/质量/格式） | 让用户知道"够好了" | 低 | 应届生 |

| 6 | **微信 OG 卡片**：`/r/[slug]` 补 og:image（复用 preview image export） | 微信是第一获客渠道 | 低 | 所有人 |

## 3. 技术架构演进建议

### 3.1 基础设施（立即收益）

| 提案 | 工作量 | 收益 |
|------|--------|------|
| **Sentry + Web Vitals** | S | 线上错误可见，5 分钟接入 |
| **`/r/[slug]` 边缘缓存**（ISR + `revalidateTag`） | S | 分享页秒开，消除 DB 命中 |
| **SWR/React Query 客户端缓存** | S | Dashboard 乐观更新，autosave 状态 |
| **连接池**（PgBouncer / Neon pooler） | S | 防并发 PDF 渲染耗尽连接 |

### 3.2 PDF 方案升级

| 方案 | 优缺点 | 建议 |
|------|--------|------|
| **A. Browserless SaaS** | 零冷启动，HTTP-in/PDF-out；有供应商依赖 | **短期首选** |
| **B. 预热 Puppeteer 池**（Fly Machine） | 保持渲染一致性，冷启动 <1s；有运维成本 | 中期方案 |
| **C. CSS @page + window.print()** | 零服务端成本；浏览器差异大 | 作为客户端快速预览补充 |
| **D. @react-pdf/renderer** | 纯 edge；需维护平行模板系统，CJK 字体坑 | 长期评估 |

### 3.3 性能优化

| 提案 | 工作量 | 效果 |
|------|--------|------|
| **TipTap 动态导入**（非编辑页不加载） | S | 首屏减 ~180KB |
| **Preview 字段级订阅**（替代全量 `useWatch()`） | M | 编辑器每次只重渲变更区块 |
| **Dashboard RSC 流式渲染** | S | 卡片列表 SSR + skeleton |
| **Partial Prerendering（PPR）** | S | Next 16 原生支持 |
| **Preview 虚拟化**（多页时仅渲染可见页） | S | 长简历无卡顿 |

### 3.4 可扩展性

| 提案 | 工作量 | 解锁能力 |
|------|--------|---------|
| **模板注册表 + manifest** | M | 新模板零改核心代码 + CLI scaffold |
| **Section 插件协议**（`{ schema, Editor, Renderer, defaultValue }`） | M | 新区块类型热插拔 |
| **Design Token 层** | M | 主题色一键切换，开放用户自定义配色 |
| **i18n via next-intl** | M | 开辟英文市场 |

### 3.5 AI 集成点

| 功能 | 接入方式 | 工作量 |
|------|---------|--------|
| **段落润色** | TipTap toolbar → `/api/ai/polish` → streaming 回写 | M |
| **ATS 关键词匹配** | 客户端 embedding 相似度 / jieba 分词 + TF-IDF | M |
| **自动生成个人总结** | 聚合所有 section → LLM → 插入个人总结模块 | S |
| **模板推荐** | 行业/角色 metadata → 规则 + LLM 推理 | S |

## 4. UX 设计方向

### 4.1 新用户 10 分钟出成品

```
落地页（案例展示）
  → 选模板（3 张卡片 + 预览）
    → 填基本信息（姓名/手机/邮箱/目标岗位）
      → 骨架简历自动生成（根据岗位预填提示文案）
        → 用户替换示例内容
          → 完成度评分引导补充
            → 导出 PDF / 分享链接
```

### 4.2 编辑器效率提升

| 功能 | 价值 | 人群 |
|------|------|------|
| **Cmd+Z/Y 操作历史**（50 步快照） | 高 | 所有人 |
| **AI 润色按钮**（每条经历旁 ✨） | 高 | 应届生 |
| **Cmd+K 命令面板**（添加经历/切模板/下载 PDF） | 中 | 跳槽者 |
| **批量排序模式**（多选 items 后移动/删除） | 中 | 跳槽者 |

### 4.3 移动端策略

> **不做编辑，做查看 + 分享 + 微调。**

- `/r/[slug]` 自适应渲染 + 底部悬浮「分享给 HR」按钮
- 仅开放基本信息修改（手机号/邮箱）
- 简历被查看时推送通知（微信/邮件）

### 4.4 反馈循环

| 机制 | 实现方式 | 复杂度 |
|------|---------|--------|
| **完成度评分**（72/100 环形进度） | 规则引擎：信息完整度 + 内容质量 + 格式规范 | 低 |
| **ATS checklist**（绿勾/红叉） | 静态规则：图片文字、表格嵌套、关键词缺失 | 低 |
| **匿名互评**（投入公共池交换反馈） | 社区机制 | 高 |

### 4.5 多页处理

1. 预览面板顶部黄色提示条：「内容已超出一页，建议精简」
2. 提供「自动分页」开关——section 边界插入分页符
3. 「一页模式锁定」——自动缩小 density/font-size 强制适配
4. 右侧页码缩略图导航

### 4.6 情感化设计

- **PDF 生成等待**：纸飞机折叠微动画
- **首次完成简历**：confetti + 「简历已准备就绪 🎉」
- **预览面板**：轻微纸张纹理 + 阴影，模拟真实打印
- **隐私安心**：底部小字「数据仅存储在你的账户中，不会被用于训练模型」
- **操作反馈**：spring 动画，柔和过渡

## 5. 变现模型

```
┌─────────────────────────────────────────────────────────────────┐
│  免费层（获客）            Pro ¥9.9/月 or ¥68/年        团队版 ¥299/年·5人  │
├─────────────────────────────────────────────────────────────────┤
│  • 3 基础模板              • 全部模板 + 新模板抢先用     • 协作评审          │
│  • 无限 PDF 导出 ✓         • AI 无限次润色/扩写/匹配    • 管理后台          │
│  • 公开分享链接            • 去水印公开链接             • 品牌定制          │
│  • 基础完成度评分          • 自定义域名                • 批量导出          │
│  • AI 每日 5 次            • 简历解析导入              • 数据统计          │
│                           • ATS 深度报告                               │
└─────────────────────────────────────────────────────────────────┘
```

**核心原则**：
- PDF 导出**永久免费**——这是用户来的原因，也是最强口碑传播点
- AI 功能 + 高级模板**付费**——这是用户留的原因
- 中文用户对年付有偏好，定价锚点：¥68/年 ≈ ¥5.7/月 < 一杯奶茶

## 7. 技术栈差异化打法

| 我们的优势 | 如何放大 |
|-----------|---------|
| TipTap 富文本 | 段落级 AI inline 改写，竞品只能整段替换 |
| 实时 A4 预览 | 打印安全区提示 + 自动分页预警 + 溢出检测 |
| Puppeteer PDF | 所见即所得零偏移，作为核心卖点反复强调 |
| Next.js 16 RSC | 首屏秒开 + SEO 友好落地页，自然流量成本低 |
| 中文原生 | 避头尾、标点挤压、中英间距——竞品都没做好 |

## 8. 用户旅程补缺地图

```
[落地]    → [注册]    → [填内容]    → [选模板]  → [导出/分享] → [投递]  → [拿面试]
  │          │           │            │           │           │         │
  │缺引导     │缺导入      │缺AI辅助     │够用        │够用        │缺追踪    │缺反馈
  │          │           │            │           │           │         │
  ▼          ▼           ▼            │           │           ▼         ▼
案例展示    PDF/文本导入  AI润色+评分    │           │         投递看板   查看统计
引导流      岗位模板库    Undo/Redo     │           │
                        溢出预警       │           │
```

**最大断点**：新用户面对空白编辑器不知如何开始。
**解法优先级**：① 三步引导流 > ② 简历导入 > ③ AI 生成初稿 > ④ 岗位模板库
